# 프로젝트3

## 프로젝트 개요
- Flutter 기반 테트리스 앱으로, 모바일/태블릿 양 플랫폼에서 일관된 UX를 제공해야 합니다.
- 초기 단계에서는 싱글 플레이 모드를 우선 구현하고, 이후 멀티플레이 확장을 고려합니다.
- 모든 UI, 위젯, 파일 이름은 PascalCase 규칙을 따르며, Flutter 디렉터리 구조(lib, test 등) 관례를 유지합니다.

## 개발 원칙
- Flutter stable 채널, Dart null-safety 활성화 상태를 기준으로 합니다.
- 상태 관리 방식은 추후 결정하되, `GameState`, `BoardController` 등 핵심 클래스는 PascalCase로 명시적으로 구분합니다.
- 위젯 레이아웃은 `Scaffold` + `SafeArea` 조합을 기본으로 하며, 핵심 화면은 `GameBoardView`, `ScorePanel`, `ControlPad` 등으로 분리합니다.
- 텍스트, 색상, 크기 등 디자인 토큰은 `ThemeData`를 통해 중앙 관리합니다.

## 테트리스 기능 요구사항

### 블록 및 보드 규칙
- 10x20 보드를 기본으로 하며, 내부 표현은 2차원 배열 또는 리스트로 관리합니다.
- 7가지 테트로미노(I, O, T, S, Z, J, L)를 모두 지원하고, 드로우 순서는 표준 7-개 백(Random Bag) 알고리즘을 활용합니다.
- 회전 시스템은 SRS(Super Rotation System)를 채택하며, 회전 실패 시 킥 테이블 로직을 적용합니다.
- 충돌 감지는 수평/수직/회전 입력 모두에 대해 프레임 단위로 수행합니다.

### 게임 루프 및 상호작용
- 틱 기반 루프를 두고, 현재 레벨에 따라 드롭 속도를 동적으로 조정합니다.
- 입력(좌/우 이동, 소프트 드롭, 하드 드롭, 회전, 홀드)은 `ControlPad` UI 또는 제스처로 연결합니다.
- 홀드 기능은 1턴당 1회만 허용하며, 미사용 시 옵션으로 비활성화할 수 있습니다.
- 라인 클리어 시 애니메이션 및 사운드를 동기화하고, 동시에 4줄 이상 삭제 시 T-Spin 여부를 판단하도록 확장 포인트를 남깁니다.

### 시스템 상태 및 지속성
- `GameState`는 현재 보드, 다음 블록 큐, 홀드 블록, 점수, 레벨, 진행 시간 등을 보유합니다.
- 일시정지 상태에서는 루프를 정지하고 오버레이 UI를 보여줍니다.
- 추후 재시작 시 상태를 복원할 수 있도록 `GameState` 직렬화를 고려합니다.

## UI 레이아웃 가이드
- 메인 화면은 세 영역으로 구성합니다.
  - `GameBoardView`: 중앙 배치, 정사각 비율 유지, `CustomPaint` 또는 `Canvas` 기반 렌더링.
  - `ScorePanel`: 상단 또는 우측에 배치해 점수, 레벨, 클리어 줄 수, 다음 블록을 표시합니다.
  - `ControlPad`: 하단 고정, 이동·회전·드롭 버튼을 명확히 구분하고, 햅틱 피드백을 제공합니다.
- 다크/라이트 모드 모두 지원하며, 색 대비(AAA 레벨)를 목표로 합니다.
- 반응형 레이아웃을 위해 `LayoutBuilder`나 `MediaQuery`로 화면 크기에 따른 패딩/버튼 크기를 조절합니다.
- 애니메이션은 `AnimatedContainer`, `AnimatedOpacity`, `TickerProviderStateMixin` 등을 사용하여 60fps를 유지합니다.

## 점수 및 레벨 규칙
- 점수 산식 예시(필요 시 조정 가능):
  - 싱글: 100 × 현재 레벨
  - 더블: 300 × 현재 레벨
  - 트리플: 500 × 현재 레벨
  - 테트리스(4줄): 800 × 현재 레벨
  - 소프트 드롭: 1점/셀, 하드 드롭: 2점/셀
- 레벨 업 조건: 누적 클리어 줄 수가 `레벨 × 10`을 초과할 때마다 레벨 +1, 드롭 속도는 레벨에 비례해 가속합니다.
- 게임 오버: 스폰 영역에 블록이 자리 잡을 수 없을 때 트리거하며, 최종 점수, 레벨, 클리어 줄 수를 결과 화면에 표시합니다.
- 점수/레벨 데이터는 `ScorePanel`과 결과 모달 양쪽에 동기화 표시하고, 향후 리더보드 연동을 위해 추상화된 저장소 인터페이스를 준비합니다.
