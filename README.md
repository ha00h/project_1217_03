# 프로젝트3

플러터 기반 테트리스 애플리케이션으로, 학습용 레퍼런스와 팀 공통 이해를 높이기 위한 기초 설계를 다룹니다. 아래 정보는 제품 범위와 추후 구현 시 지켜야 할 기준을 제공합니다.

## 기능 범위
- 핵심 플레이 루프: 블록 생성 → 이동/회전 → 라인 클리어 → 점수 갱신
- 사용자 입력: 온스크린 컨트롤러와 키보드(웹/데스크톱 빌드 시) 양쪽 지원
- 진행 상태 저장: 일시 정지, 현재 점수 및 레벨 유지
- 튜토리얼과 기본 설정(낮/밤 모드 등) 제공을 목표로 확장

## UI 개요
- 홈 화면: 게임 시작, 튜토리얼, 환경설정 진입
- 게임 화면: 상단 HUD(점수·레벨·다음 블록), 중앙 플레이 필드, 하단 컨트롤러
- 일시 정지/결과 화면: 재개·재시작·홈 이동, 기록 공유
- 반응형 레이아웃을 전제로 모바일 우선 설계

## 화면 흐름
1. `HomeScreen` → `GameScreen`
2. 게임 중 `PauseOverlay` 또는 `ResultDialog`
3. `SettingsScreen`/`TutorialScreen`은 홈에서 분기 후 복귀

## 기술 스택
- Flutter 3.x / Dart 최신 안정 버전
- 상태 관리: Provider 혹은 Riverpod (최종 결정 전 협의)
- 빌드 타깃: Android, iOS, Web 데스크톱(선택)
- 테스트: Flutter test + golden test

## 파일 명명 규칙
- 모든 다트 파일·위젯 클래스는 PascalCase 사용 (예: `GameBoard.dart`, `ScorePanel.dart`)
- 디렉터리 구조는 기능 단위로 묶되, 공통 위젯과 서비스는 `shared/` 하위에 배치
